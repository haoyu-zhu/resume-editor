# 简历生成器

在浏览器里做中文简历：**直接在纸面上改字**，拖滑块调版面松紧，增删条目，打印成 PDF。

---

## 怎么用

**[下载 ZIP](https://github.com/haoyu-zhu/resume-editor/archive/refs/heads/main.zip) → 解压 → 双击 `index.html`。** 不用装任何东西，不用联网，浏览器打开就能用。

也可以直接开在线版：**<https://haoyu-zhu.github.io/resume-editor/>**

> 双击本地文件打开时（`file://`），浏览器会禁掉 localStorage，**不会自动保存**改到一半的内容——改完记得按 <kbd>Ctrl</kbd>+<kbd>S</kbd> 把 JSON 存下来。想要自动保存，用上面的在线版，或者在本地起个服务（见文末）。

第一次打开会有一份填满一页的示例简历（人物出自《围城》），**直接在它上面改就行**。同时会自动跑一遍新手指引，气泡加箭头把功能挨个指一遍，<kbd>Esc</kbd> 可以随时跳过；之后想重看，点左边栏的「新手指引」。

不想在示例上改，就点左边栏「新建空白简历」。

## 它是什么

- **纯静态**，没有构建步骤，没有后端。丢到任何静态托管上就能跑。
- **简历不出浏览器。** 简历文字和照片全程只在本机的内存和 localStorage 里，从不发往任何服务器。
  官方站点有匿名使用统计，但它只数数和计时，碰不到简历内容 —— 逐字段清单见
  [统计了什么](#统计了什么)。
- **所见即所得。** 屏幕上那张纸的尺寸、字号、间距就是打印出来的 A4，没有二次转换。
- **一页一张纸。** 内容多了自动排到下一张，跨页的整段经历会被整块推下去，不会被切成两半。屏幕上排到第几页，打印出来就是第几页。
- **实时告诉你排满了没有。** 设一个目标页数，超了才报红。

适合：中文校招 / 实习 / 社招简历，一到三页，有证件照。

## 常用操作

| 想干什么 | 怎么做 |
|---|---|
| 改字 | 直接点纸上的文字。回车不会造出换行；粘贴自动去格式 |
| 加粗 | 划选一段字按 <kbd>Ctrl</kbd>+<kbd>B</kbd>，再按取消。用来挑出关键数字 |
| 上色 | 划选一段字，点「文字」面板的色块。五个颜色和主题色同一组但**不跟着主题变**；末尾 `✕` 去色。省着用 |
| 加一行 / 一段经历 | 板块标题**右边**的 `＋`；给某段经历加要点用那段标题右边的 `＋要点` |
| 排序 / 改链接 / 删除 | 鼠标移到某行，**右边**冒出 `⠿ 🔗 ✕`。也可以光标进入某行按 <kbd>Alt</kbd>+<kbd>↑↓</kbd> |
| 补回删空的字段 | 该行**左边**会出现 `＋标签` `＋图标` 之类的按钮 |
| 把一条要点写成概述 | 点要点右边的 `¶`，前面的蓝方块和缩进一起去掉，整条变成一段平铺的话；左边的 `＋方块` 加回来 |
| 换 / 去掉板块图标 | 点标题左边的图标；选择器末尾的 `✕` 去掉一个，底部「全部去掉」清空所有 |
| 加板块 | 左边栏「添加板块」，十五种预设或自定义标题 |
| 调版面 | 十档预设 + 十一个滑块（字号、行距、各种间距、照片宽度、上下左右留白） |
| 换主题色 | 五套预设或自己取色。**深色系在黑白打印机上更稳** |
| 撤销 / 重做 | <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>，或标题右边那对箭头 |
| 存档 | 浏览器自动记住；<kbd>Ctrl</kbd>+<kbd>S</kbd> 下载 JSON（**版面参数、主题色一起带走**） |
| 推荐给别人 | 右上角的分享图标。复制一张图（图里带二维码和网址）直接粘进微信 |

**「版面占用」**在左边栏实时反馈：蓝色 = 页数达标且排得饱满，橙色 = 偏空或末页只剩零星几行，红色 = 超过目标页数。

排不下的时候，**先调页边距（上下左右留白）再考虑压字号**——伤害小得多。

## 手机上

屏幕窄于 820px 时，左边栏收成抽屉：点左上角的按钮拉出来，点旁边的空白、按
<kbd>Esc</kbd>、或者再点一次按钮收回去。纸这时占满整个屏幕，还是完整的一张 A4，
只是缩得小。

**手机适合看和小改，不适合从零写一份。** 字段小、按钮密，真正排版还是回电脑上。

## 出 PDF

点「打印 / 存成 PDF」（或 <kbd>Ctrl</kbd>+<kbd>P</kbd>），在打印对话框里确认三件事：

| 设置 | 要选 | 不改会怎样 |
|---|---|---|
| 页眉和页脚 | **关掉** | 纸上印出网址和日期 |
| 背景图形 | **勾上** | 蓝色横线和图标全部消失 |
| 纸张 / 边距 | A4 / 默认 | 页边距对不上 |

然后选「另存为 PDF」。设对一次以后可以勾「以后别再提示我」。

**关于「页眉和页脚」**：默认参数下**它根本不会出现**，那一条提示也不会显示——浏览器只在页边距留得下的时候才画页眉页脚，实测阈值是 8mm，而默认的页顶/页底留白正好是 0.8cm，压在线下。

只有把侧栏的**「页顶留白」或「页底留白」调到 0.8 以上**，浏览器才会开始往纸上印日期和网址（顶大出页眉、底大出页脚，互不相干）。真调大了的话，滑块下面会当场出现一行黄色提示，附带一个「调回 0.8」的按钮；打印提示里那一条也会跟着标黄，并写明是哪根滑块调到了多少。就算之前勾过「以后别再提示我」，这种情况也仍然会拦一次。

> 想彻底不管这件事，也可以在 `@page` 里声明六个空的 margin box 把浏览器的默认内容顶掉（Chrome / Edge 131+ 实测有效）。本项目**没有采用**：那要在 `@page` 里嵌套 at-rule，万一哪个解析器把整条 `@page` 判废，页边距会退回浏览器默认，属于全局版面事故——不值得为省一次提示去冒这个险。详见 `assets/app.js` 里 `HF_GUIDE` 那段注释。

文件名是 `姓名-求职岗位.pdf`，没填岗位就只有姓名。

## 分享

右上角的分享图标弹出一张图：示例简历的**真实渲染**加一条底部横幅，横幅上有网址和二维码。
桌面端一打开就把图写进剪贴板，粘到微信直接发；手机端长按保存。

网址之所以要印在图里，是因为**剪贴板一次粘贴只能拿到图片或文字，不能两个都要**
（`ClipboardItem` 里放多个 MIME 是同一份内容的备选表示，接收方只挑一种，微信挑图片）。
链接不在图里的话，用户得发两次。

二维码和「只复制链接」都指向主页。**代价是数不出分享带来了多少人** ——
统计里虽然有来路域名，但从微信、二维码、以及图里那行网址点进来的都没有来路，
恰好就是分享的主要路径。想数准就得给分享链接一个自己的路径（比如 `/s/` 停一下再跳回主页）。
现在的量级下那个数每天是个位数噪声，不值得为它多一个页面和一次跳转。

换图：改 `tools/make-share.py` 顶上的构图参数，跑 `python tools/make-share.py`。
它重新渲染一遍示例简历，所以**改了版面样式重跑一次就同步了**，不会和产品脱节。

分享的是**这个网站**，不是用户的简历 —— 简历上有手机号和住址，做成一键分享只会变成误发的地雷。

## 统计了什么

官方站点 `haoyu-zhu.github.io/resume-editor/` 有两处匿名统计。
自己部署的话，删掉 `index.html` 末尾那段 beacon、并把 `assets/metrics.js`
里的 `ENDPOINT` 留空，两处就都关了。

**这里不存在「我们只是不看」的说法。** 下面每个字段都是白名单里写死的，
接收端（`analytics/src/index.js`）没有能装下姓名、电话、邮箱或经历正文的地方 ——
不在名单里的字段在入库之前就被丢了。

### 1. Cloudflare Web Analytics

访问量、页面加载耗时、来路。无 Cookie，不做用户画像。这是 Cloudflare 的现成服务。

### 2. 自建埋点（`analytics/`，源码在同一个仓库里）

回答两个问题：**有多少人真的做出了一份简历**，以及**他们在这儿待了多久**。
Cloudflare Web Analytics 两个都答不了 —— 它没有自定义事件，也无法把同一次访问的动作串起来。

发生这些事的时候各发一条：

| 事件 | 什么时候 |
|---|---|
| `open` | 页面载入完成，带上是以什么方式打开的 |
| `print` | 点了打印 |
| `download` | 下载了 `.json` |
| `tour_done` / `tour_skip` | 新手指引走完 / 中途退出 |
| `leave` | 标签页转入后台或关闭，结算这一段的有效停留时长 |

每条里带的**全部**字段：

| 字段 | 值 | 说明 |
|---|---|---|
| 事件名 | 上表七选一 | 不在表里的请求直接 400 |
| 打开方式 | `first` / `empty` / `restore` / `blank` / `sample` / `json` / `paste` / `demo` | 枚举，不在表里记成 `other` |
| 有效停留秒数 | 0–10800 | 只累计**标签页可见**的时间；超 3 小时判为异常丢弃 |
| 页数 | 0–50 | 简历排了几页，是个数字 |
| 板块数 | 0–200 | 简历有几个板块，是个数字 |
| 来路域名 | 如 `www.google.com` | **只取域名**，路径和 query 在入库前被削掉 |
| 设备 | `mobile` / `desktop` | 视口是否 ≤820px |
| 国家 | 如 `CN` | Cloudflare 边缘本来就知道，**IP 一个字节都不落** |
| 前端版本 | 如 `2026-09` | 区分改版前后的数据 |
| 会话串 | 随机 UUID | 存在 `sessionStorage`，**关掉标签页就失效**，跨访问认不出同一个人 |
| 时间戳 | 服务端时间 | 不信客户端的表 |

没有的东西：**Cookie、跨访问的持久标识、IP、简历里的任何一个字**。

想自己看数：`python analytics/report.py --days 30`（需要先 `npx wrangler login`）。

## resume.json

「下载改好的 JSON」存的就是这份简历的**底本**——内容、版面参数、主题色全在里面，下次打开原样恢复，也可以发给别人。格式见 [SCHEMA.md](SCHEMA.md)。

格式里**没有任何和岗位、职能相关的字段**，一份简历就是「顶部信息 + 若干板块」，板块只有四种形态。别的工具照着 SCHEMA 生成的 JSON，这里也能直接打开。

浏览器的自动存档只是图方便——换台机器、清一次浏览数据就没了。**真正的底本是那份 JSON。**

## 已知限制

- **字体**：设计基准是 Noto Sans SC，机器上没有会退到微软雅黑 / 苹方，字宽略有差别，原本刚好一页的内容可能溢出一点。「版面占用」会实时提示。
- **屏幕分页是估算**。它复刻了打印时的整块避让规则，测试里和实际打印完全吻合，但字体差异极端情况下可能差一两行。**以打印预览为准。**
- **单段经历超过一整页**时，会退而允许它在要点之间断开——否则页底会空出一大片。
- **拖拽只在同类之间生效**：要点只能落到要点之间，板块只能落到板块之间。
- 面向中文简历。英文简历、学术 CV 的排版惯例不同，不在射程内。

## 给想改代码的人

```
index.html          页面结构
assets/resume.css   简历版面（纸上的一切都由它定义，改视觉风格改这里）
assets/style.css    编辑器界面（打印时全部隐藏）
assets/render.js    JSON -> DOM
assets/app.js       编辑逻辑：改字回写、增删、拖拽、撤销、分页、版面变量、导出
assets/tour.js      新手指引（步骤表 + 气泡摆位 + 打圈箭头，自成一支）
assets/sample.js    示例简历，也是首次打开时纸上的默认内容
assets/metrics.js   匿名使用统计的前端（ENDPOINT 留空就整个关掉）
assets/photo.js     默认占位证件照（data URI，由 tools/make-photo.py 生成）
assets/icon.png     标签页图标（由 tools/make-icon.py 生成）
Fig/                上面两个的原图，产品运行时不读它
assets/share.png    分享弹窗里那张图（由 tools/make-share.py 生成）
tools/serve.py      本地预览服务器（带禁缓存头，改完刷新就见效）
tools/make-share.py 重做 assets/share.png（真实渲染示例简历 + 横幅 + 二维码）
analytics/          埋点接收端（Cloudflare Worker + D1）与报表脚本，自己部署可以整个删掉
```

**改版面样式只改 `assets/resume.css` 的 `:root` 变量**，不要在 `render.js` 生成的 HTML 里写死尺寸——那会让预览和打印对不上。

**本地预览**：`python tools/serve.py` → <http://localhost:8765/>。比 `python -m http.server` 多做一件事：每个响应都带禁用缓存的头，否则改了文件刷新也看不到变化。

**换占位证件照 / 标签页图标**：新图放进 `Fig/`，跑 `python tools/make-photo.py` 或 `python tools/make-icon.py`。产品本身仍然零构建步骤，这两个脚本只在换图时才用。

**关掉统计**：`assets/metrics.js` 顶上的 `ENDPOINT` 留空 + 删掉 `index.html` 末尾那段
Cloudflare beacon。想接自己的：`cd analytics && npx wrangler d1 create ...`，把
`wrangler.jsonc` 里的 `database_id` 换成自己的，`npx wrangler d1 execute <库> --remote
--file migrations/0001_init.sql` 建表，`npx wrangler deploy`，再把 `src/index.js` 里的
`ALLOWED_ORIGINS` 换成自己的域名。**改那个文件之前先读它开头的三条铁律。**

**部署**：推到 GitHub，仓库 Settings → Pages → Source 选 Deploy from a branch，Branch 选 main / (root)。换任何静态托管都一样，把这些文件原样放上去即可。带 `#demo` 的链接会绕开访客的本地存档强制载入示例，适合发出去给人看效果。
