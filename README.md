# 简历微调器

在浏览器里做一页纸中文简历：**直接在纸面上改字**，拖滑块调版面松紧，增删条目，打印成 PDF。

- **纯静态**，没有构建步骤，没有后端。丢到任何静态托管上就能跑。
- **数据不出浏览器。** 简历内容和照片全部只在本机，不上传任何服务器。
- **所见即所得。** 屏幕上那张纸的尺寸、字号、间距就是打印出来的 A4，没有二次转换。
- **实时告诉你排满了没有。** 几页、末页占了多少，边改边看。

适合：中文校招 / 实习简历，一页纸，有证件照。

---

## 三种开始方式

| 方式 | 适合 |
|---|---|
| **新建空白简历** | 手上什么都没有，从骨架开始填 |
| **打开 `resume.json`** | 已经有格式正确的 JSON（自己导出的，或者别的工具生成的） |
| **看示例** | 先看看做出来长什么样 |

`resume.json` 的格式见 [SCHEMA.md](SCHEMA.md)。格式里**没有任何和岗位、职能相关的字段**，一份简历就是「顶部信息 + 若干板块」，板块只有四种形态。

---

## 怎么用

**改字** —— 直接点纸上的文字改，和改文档一样。回车被禁用了，简历的一格里不该有换行；粘贴会自动去掉格式。

**改结构** —— 鼠标移到某一行上：

- **右边**冒出 `↑ ↓ ✕`：上移、下移、删除
- **左边**冒出 `＋`：加一行 / 加一段经历 / 加一条要点

板块级的按钮在板块标题那一行，条目级的在条目标题那一行。新加的行带占位文字，光标会自动落上去并选中，直接打字就覆盖。

**加板块** —— 左边栏「添加板块」：证书、语言能力、荣誉奖项、作品集、工作 / 科研 / 竞赛经历、论文专利，或者自定义标题。新板块插在「自我总结」前面，位置不合适用 `↑` 挪。

**调版面** —— 十档预设 + 八个滑块（字号、行距、要点间距、条目间距、板块间距、标题到横线、横线到正文、照片宽度）。左上角「版面占用」实时反馈：

| 颜色 | 含义 | 该做什么 |
|---|---|---|
| 蓝 | 一页，排得饱满 | 就这样 |
| 橙 | 一页，但下半张偏空 | 调大字号，或者把经历写透一点 |
| 红 | 超出一页了 | 调紧，或者删掉不相关的内容 |

**照片** —— 「换一张」上传，自动缩到 420px 宽，不用自己先压缩。也可以「不要照片」。

**存档** —— 浏览器自动记住改到一半的内容，关掉再打开还在。「下载改好的 JSON」可以留着下次接着改，或者发给别人。

## 出 PDF

点「打印 / 存成 PDF」，在浏览器的打印对话框里确认三件事：

| 设置 | 要选 | 不改会怎样 |
|---|---|---|
| 页眉和页脚 | **关掉** | 纸上印出网址和日期 |
| 背景图形 | **勾上** | 蓝色横线和图标全部消失 |
| 纸张 / 边距 | A4 / 默认 | 页边距对不上 |

然后选「另存为 PDF」。

## 部署到 GitHub Pages

```bash
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

仓库 **Settings → Pages → Build and deployment**：Source 选 **Deploy from a branch**，Branch 选 **main** / **(root)**。

一两分钟后就能访问 `https://<用户名>.github.io/<仓库名>/`，带 `#demo` 的链接会自动载入示例简历，适合发出去给人看效果。

> 仓库里是什么就 serve 什么，改完 push 一下就生效。换任何静态托管（Vercel、Netlify、对象存储、自己的 nginx）都一样，把这几个文件原样放上去即可。

## 文件

```
index.html          页面结构
SCHEMA.md           resume.json 格式规范
assets/resume.css   简历版面（纸上的一切都由它定义，改视觉风格改这里）
assets/style.css    编辑器界面（打印时全部隐藏）
assets/render.js    JSON -> DOM
assets/app.js       编辑逻辑：改字回写、增删、移动、撤销、版面变量、导出
assets/sample.js    示例简历（虚构数据）
```

**改版面样式只改 `assets/resume.css` 的 `:root` 变量**，不要在 `render.js` 生成的 HTML 里写死尺寸——那会让预览和打印对不上。

## 已知限制

- **字体**：设计基准是 Noto Sans SC，机器上没有会退到微软雅黑 / 苹方，字宽略有差别，原本刚好一页的内容可能溢出一点。「版面占用」会实时提示，按提示调即可。
- **清空标签会让它消失**：把某条要点的蓝色标签删成空，下次重新渲染时标签连同冒号一起没了。想要回来就删掉这条重新加。同理还有教育行的 `tag` 和 `degree`。
- **本地双击打开**（`file://`）功能正常，但浏览器会禁掉 localStorage，**不会自动保存**。用 http(s) 地址访问就没这个问题。
- **打印分页由浏览器决定**，「版面占用」是估算，极端情况下可能差一两行。
- 只做一页纸中文简历。英文简历、学术 CV、两页以上的社招简历都不在射程内。
