# 简历生成器

在浏览器里做中文简历：**直接在纸面上改字**，拖滑块调版面松紧，增删条目，打印成 PDF。

- **纯静态**，没有构建步骤，没有后端。丢到任何静态托管上就能跑。
- **数据不出浏览器。** 简历内容和照片全部只在本机，不上传任何服务器。
- **所见即所得。** 屏幕上那张纸的尺寸、字号、间距就是打印出来的 A4，没有二次转换。
- **一页一张纸。** 内容多了就自动排到下一张纸上，跨页的整段经历会被整块推到下一页，不会被切成两半。屏幕上排到第几页，打印出来就是第几页。
- **实时告诉你排满了没有。** 设一个目标页数，超了才报红。

适合：中文校招 / 实习 / 社招简历，一到三页，有证件照。

---

## 开始

**第一次打开会有一份填满一页的示例简历**（人物出自《围城》），直接在纸上改字就行——空白页看不出这个工具能做什么，改现成的也比从零填快。

示例**只出现这一次**：动过它，它就转正成你自己的简历，关掉再来还是你改的那份；没动过就当没来过，下次打开是空白起始页，示例不会再冒出来。

想换个起点，用左边栏：

| 方式 | 适合 |
|---|---|
| **新建空白简历** | 不想在示例上改，从骨架开始填 |
| **打开 `resume.json`** | 已经有格式正确的 JSON（自己导出的，或者别的工具生成的） |
| **看示例** | 把示例重新调出来（会覆盖当前内容） |

`resume.json` 的格式见 [SCHEMA.md](SCHEMA.md)。格式里**没有任何和岗位、职能相关的字段**，一份简历就是「顶部信息 + 若干板块」，板块只有四种形态。

## 新手指引

**第一次打开会自动跑一遍**：气泡加一支打圈的箭头，把十四个功能挨个指过去——纸上改字、加粗、行内的增删按钮、板块图标、版面滑块、主题色、版面占用、导出。<kbd>←</kbd> <kbd>→</kbd> 翻页，<kbd>Esc</kbd> 或「跳过」随时退出。

只自动跑这一次。之后想重看，点左边栏「开始」里的**新手指引**。

指引会临时把那些平时藏起来的按钮（行右边的 `⠿ 🔗 ✕`、标题右边的 `＋`）逼出来，否则箭头会指向一片空气；退出时一并收回，不留痕迹。

## 怎么用

**改字** —— 直接点纸上的文字改，和改文档一样。回车不会在格子里造出换行（简历的一格里不该有换行），在顶部信息区它另有用处，见下面「顶部信息区」；粘贴会自动去掉格式。

**加粗** —— 划选一段字，按 <kbd>Ctrl</kbd>+<kbd>B</kbd>，再按一次取消。用来在一条长要点里把关键数字挑出来（「转化率从 **31%** 提到 **39%**」），HR 扫简历时先看见的就是它。存进 JSON 是 `**这样**`，一眼能看懂，也不会把 HTML 带进数据里。粘贴进来的加粗不算数——粘贴一律去格式，加粗只能自己按。

**加东西** —— 每个板块标题**右边就挂着「＋」**（`＋一行` / `＋一段经历` / `＋学校 ＋备注`），平时淡淡的，鼠标移上去变清晰，点了就往这个板块里加。往某段经历里加要点，用那段经历标题右边的 `＋要点`。

**改结构** —— 鼠标移到某一行上，**右边**冒出 `⠿ 🔗 ✕`：拖动排序、改链接、删除。被删空的可选字段（要点的标签、院校标记、学位）会在该行**左边**给出 `＋标签` 之类的按钮补回来。

**按钮不会在你走过去的路上消失** —— 把光标点进哪一行，那一行（和它外面一层）的按钮就**钉住不动**，可以慢慢移过去点，按 <kbd>Esc</kbd> 收起。纯靠鼠标悬停也行：按钮和行之间没有空隙，鼠标移开之后还有 0.4 秒仍然点得到的宽限期。

新加的行带占位文字，光标会自动落上去并选中，直接打字就覆盖。**新的一条加在光标所在那一条的后面**，不是一律甩到末尾 —— 想往中间插，先把光标点到插入位置的上一条。

**排序** —— 拖 `⠿`，或者把光标放进某一行按 <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd>。板块、经历、要点、教育行、技能行、顶部信息区的行和字段都能拖。要点可以拖到**另一段经历**里去，顶部的字段可以拖到**另一行**去；其它的只在自己所属的板块内部移动。

**顶部信息区** —— 这一块是「行 → 字段」两层：`＋一行` 挂在姓名右边，`＋字段` 挂在每一行左边。字段是横着往右排的，排不下会自动折到下一行，**折行位置由你定**：

| 想干什么 | 怎么做 |
| --- | --- |
| 在某个字段后面插一个新字段 | 光标点进那个字段，再点该行左边的 `＋字段` |
| 从某个字段起另起一行 | 光标点进那个字段按 <kbd>Enter</kbd>，或点它上方的 `↵` |
| 把一行接回上一行 | 点该行第一个字段上方的 `⤴` |
| 把某个字段挪到另一行 | 拖它的 `⠿` |

字段的按钮浮在字段**正上方**（一张白底小卡片），不会压住同一行的邻居。

**换图标 / 去掉图标** —— 直接点板块标题左边那个小图标，十个里挑一个，或者点最后那个 <b>✕</b> 把这个板块的图标去掉。选择器底下的「全部去掉」一次清掉所有板块的图标。

去掉之后，板块标题右边的「＋」里会多出一个 `＋图标`，点它就地把选择器叫回来。手滑了按 <kbd>Ctrl</kbd>+<kbd>Z</kbd>，「全部去掉」也在撤销范围内。

**加链接** —— 点 `🔗`，填地址。想取消链接就把地址清空。没写 `https://` 会自动补上。

**加板块** —— 左边栏「添加板块」，十五种预设分三组（经历类 / 清单类 / 其它），或者自定义标题。新板块插在「自我总结」前面，位置不合适拖 `⠿` 挪。

**分页** —— 内容超过一页就自动多出一张纸，两张纸之间留出灰色间隔，右下角标着页码。跨页的整段经历、整条要点、板块标题都会被**整块推到下一页开头**，和打印时的行为一致（这一点是逐页比对过的：屏幕上几页，打印出来就是几页）。

**目标页数** —— 默认 1 页（校招常规），可以改成 2 页、3 页或不限。只有**超过目标**才报红。

**调版面** —— 十档预设 + 十个滑块（字号、行距、要点间距、条目间距、板块间距、标题到横线、横线到正文、照片宽度、页顶留白、页底留白、左右留白）。上下留白直接改的是 A4 的页边距，屏幕和打印同步生效；差一两行放不下时，先动它比压字号伤害小。左上角「版面占用」实时反馈：

| 颜色 | 含义 | 该做什么 |
|---|---|---|
| 蓝 | 页数在目标之内，排得饱满 | 就这样 |
| 橙 | 版面偏空，或者末页只有零星几行 | 调大字号补厚内容，或者压回上一页 |
| 红 | 超过了目标页数 | 调紧，或者删掉不相关的内容 |

**主题色** —— 五套预设（蓝 / 墨黑 / 深绿 / 酒红 / 靛紫），或者自己取色。标签、横线、图标、链接会一起换。深色系在黑白打印机上更稳。

**照片** —— **打开就有一张占位证件照**，一眼能看出照片放哪、多大合适（没设置过照片的简历都会自动补上）。「换一张」上传自己的，自动缩到 420px 宽，不用先压缩；「不要照片」会记住这个选择，刷新也不会又冒出来。

换掉默认占位图：把新图放进 `Fig/`，跑 `python tools/make-photo.py` 重新生成 `assets/photo.js`。

换掉标签页图标同理：新图放进 `Fig/`，跑 `python tools/make-icon.py` 生成 `assets/icon.png`。脚本会自动裁掉四周留白再补成正方形——favicon 只有 16~32px，不裁的话主体缩完就是一团灰。
脚本会自动缩到 420px、转 JPEG、带 alpha 的先合成白底 —— 和产品里上传照片的处理完全一致。

**反悔** —— 侧栏标题「简历生成器」右边有一对反向箭头：**↶ 撤销、↷ 重做**，没得可撤/可重做时是灰的。快捷键 <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>。增删、移动、换图标、改字都在撤销范围内；改字是「一个字段一档」，正在某个字段里打字的时候 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 走浏览器自己的逐字撤销，字面回到进场时的样子之后再按就接着往前撤。「还原全部」直接回到刚导入时。

**存档** —— 浏览器自动记住改到一半的内容，关掉再打开还在。存不下的时候（多半是证件照太大撑爆了配额）侧栏会给出橙色警告，这时候必须自己下载 JSON。

改过而**还没导出 JSON** 时，「下载改好的 JSON」按钮会亮起来标上「·未导出」，关页面时浏览器也会拦一下问你确不确定。（那个对话框的文案是浏览器自己的，改不了，所以按钮同时亮起来告诉你该点哪里。）本地存档只是图方便——换台机器、换个浏览器、清一次浏览数据它就没了，简历的真正底本是那份 JSON。

「下载改好的 JSON」把**版面参数、主题色、目标页数一起带走**，下次打开原样恢复，也可以发给别人。快捷键 <kbd>Ctrl</kbd>+<kbd>S</kbd>。

## 出 PDF

点「打印 / 存成 PDF」（或 <kbd>Ctrl</kbd>+<kbd>P</kbd>），在浏览器的打印对话框里确认三件事：

| 设置 | 要选 | 不改会怎样 |
|---|---|---|
| 页眉和页脚 | **关掉** | 纸上印出网址和日期 |
| 背景图形 | **勾上** | 蓝色横线和图标全部消失 |
| 纸张 / 边距 | A4 / 默认 | 页边距对不上 |

然后选「另存为 PDF」。这三项设对一次以后，可以在提示框里勾「以后别再提示我」。

**文件名**是 `姓名-求职岗位.pdf`（`meta.target_title` 空着就只有姓名，两者都空就是 `简历.pdf`）。浏览器拿网页标题当默认文件名，所以进打印前会把标题临时换成这个、出来再换回去——从浏览器菜单里打印也一样管用。

## 本地预览

直接双击 `index.html` 就能用，但 `file://` 下浏览器会禁掉 localStorage（不会自动保存）。
要完整体验就起个本地服务：

```bash
python tools/serve.py     # http://localhost:8765/
```

比 `python -m http.server` 多做一件事：**每个响应都带禁用缓存的头**。
默认那个只发 `Last-Modified`，浏览器会自作主张用旧副本，改了文件刷新也看不到变化。

## 部署到 GitHub Pages

```bash
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

仓库 **Settings → Pages → Build and deployment**：Source 选 **Deploy from a branch**，Branch 选 **main** / **(root)**。

一两分钟后就能访问 `https://<用户名>.github.io/<仓库名>/`。带 `#demo` 的链接会**绕开本地存档**强制载入示例，对方就算改过自己的简历，点进来看到的也是干净的示例，适合发出去给人看效果。

> 仓库里是什么就 serve 什么，改完 push 一下就生效。换任何静态托管（Vercel、Netlify、对象存储、自己的 nginx）都一样，把这几个文件原样放上去即可。

## 文件

```
index.html          页面结构
SCHEMA.md           resume.json 格式规范
assets/resume.css   简历版面（纸上的一切都由它定义，改视觉风格改这里）
assets/style.css    编辑器界面（打印时全部隐藏）
assets/icon.png     浏览器标签页图标（由 tools/make-icon.py 生成）
assets/tour.js      新手指引（步骤表 + 气泡摆位 + 打圈箭头，自成一支）
assets/render.js    JSON -> DOM
assets/app.js       编辑逻辑：改字回写、增删、拖拽排序、撤销/重做、分页、版面变量、主题色、导出
assets/sample.js    示例简历（《围城》方鸿渐），也是首次打开时纸上的默认内容
assets/photo.js     默认占位证件照（data URI，由 tools/make-photo.py 生成）
Fig/                占位图和图标的原图，产品运行时不读它
tools/make-photo.py 换占位证件照时才用
tools/make-icon.py  换标签页图标时才用；产品本身仍然零构建步骤
tools/serve.py      本地预览服务器（带禁缓存头，改完刷新就见效）
```

**改版面样式只改 `assets/resume.css` 的 `:root` 变量**，不要在 `render.js` 生成的 HTML 里写死尺寸——那会让预览和打印对不上。

## 已知限制

- **字体**：设计基准是 Noto Sans SC，机器上没有会退到微软雅黑 / 苹方，字宽略有差别，原本刚好一页的内容可能溢出一点。「版面占用」会实时提示，按提示调即可。
- **本地双击打开**（`file://`）功能正常，但浏览器会禁掉 localStorage，**不会自动保存**。用 http(s) 地址访问就没这个问题。
- **拖拽只在同类之间生效**：要点只能落到要点之间，板块只能落到板块之间。拖到不接受的地方不会有蓝色插入线，松手也不会有任何变化。
- **屏幕分页是估算**。它复刻了打印时的整块避让规则，页数在测试里和实际打印完全吻合，但字体不同会带来细微差异，极端情况下可能差一两行。真正的分页永远以打印对话框里的预览为准。
- **单段经历超过一整页**时，会退而允许它在要点之间断开——否则页底会空出一大片。
- 面向中文简历。英文简历、学术 CV 的排版惯例不同，不在射程内。
