简历生成器

自动保存已停用。内容超出了浏览器的存储配额（多半是证件照太大）。 现在关掉页面就会丢，请用下面的「下载改好的 JSON」自己存一份。

开始

添加板块

新板块会插在「自我总结」前面。想换位置，拖板块标题右边的 ⠿。
每个板块标题右边就有「＋」，点它往这个板块里加东西。

文字

在纸上划选一段字，点这里或按 Ctrl+B，再来一次取消。
用来把一条长要点里的关键数字挑出来。

版面松紧

主题色

标签、横线、图标、链接会一起跟着换。深色系印出来更稳，越浅的颜色越容易在黑白打印机上糊掉。

版面占用

—

超过目标页数才会报红。内容多了会自动排到下一张纸上， 跨页的整段经历会被整块推到下一页，不会被切成两半。

照片

会自动缩到 420px 宽，不用先自己压缩。

反悔

撤销 / 重做在标题右边那两个箭头上，快捷键 Ctrl+Z / Ctrl+Shift+Z。 在某个字段里打字时，Ctrl+Z 走浏览器自己的逐字撤销。 「还原全部」直接回到刚导入时。

导出

快捷键 Ctrl+P / Ctrl+S。 下载的 JSON 连版面参数和主题色一起带走，下次打开原样恢复。

显示比例

只影响屏幕上看着大小，不影响打印。

📄

从「新建空白简历」开始

已经有 resume.json 的话，把它拖到这里就行。
想先看看长什么样，点左边的「看示例」。

打印前，请在打印对话框里确认三件事

  1. 页眉和页脚：关掉。不关的话纸上会印出网址和日期。
    （Chrome：展开「更多设置」→ 取消勾选「页眉和页脚」）
  2. 背景图形：勾上。不勾的话彩色横线和图标会全部消失。
  3. 纸张 A4、边距选「默认」。页边距已经写在网页里了，不用自己调。

目标是「另存为 PDF」。如果版面和预览不一样，回来检查上面三项。
